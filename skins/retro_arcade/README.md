# Retro Arcade

Original 2D character and skin background generated with the built-in imagegen tool for CandyLauncher. The PNG includes a dark left search panel and transparent outer pixels. The matching skin uses the PNG alpha channel for the window shape.

Prompt: original polished 2D anime illustration of an adult retro arcade character on the right, with a quiet dark panel on the left for launcher controls; landscape 3:2, transparent outside the artwork, no UI text or logos.
