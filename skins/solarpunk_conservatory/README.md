# Solarpunk Conservatory

Sunlit greenhouse and botanist skin for CandyLauncher. The original transparent PNG background was generated with the built-in imagegen tool. The skin clips the launcher window to the PNG alpha channel.

Prompt: original polished 2D illustration of sunlit greenhouse and botanist on the right, quiet left panel for launcher controls, landscape 3:2, transparent outside the artwork, no text or logos.
