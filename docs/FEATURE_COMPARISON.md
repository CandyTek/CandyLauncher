# CandyLauncher 功能全览与同类软件对比清单

> 基于当前仓库的 `CLAUDE.md`、`README.md`、`common/settings.json`、主程序、插件源码和根 `CMakeLists.txt` 整理。本文描述代码中可见的能力，不代表所有能力已在同一个发行包中开启，也不包含未经实测的性能结论。

## 一句话定位

CandyLauncher 是面向 Windows 的轻量级、可用键盘快速操作的启动器。它将应用、文件、窗口、浏览器内容、开发项目和实用工具统一为搜索结果，通过原生 C++ 插件及 Node.js 脚本桥接扩展。项目 README 将“快速显示匹配结果、较低内存占用、模糊搜索和拼音匹配、Windows 7+”列为目标；速度、内存和系统兼容性应在对比时实测。

## 对比时先看这几项

| 维度 | CandyLauncher 已有能力 | 对比时建议检查 |
| --- | --- | --- |
| 中文搜索 | 中文条目可预处理为拼音；提供全拼和 8 种双拼方案；模糊匹配及分数阈值可调 | 同一批中文应用名称的全拼、首字母、双拼、错字召回与排序 |

| 结果操作 | 键盘选择和数字键执行；文件结果支持管理员运行、打开所在位置、复制路径、拖放等 | 是否需要鼠标、操作是否可自定义、快捷方式目标处理 |
| 扩展 | 原生 DLL 插件接口、插件浏览与启停、Node.js 脚本桥接 | 插件安装/隔离、社区生态、API 稳定性和运行依赖 |

| 窗口行为 | 弹出屏幕与偏移可配；可按全屏、置顶全屏及指定游戏进程抑制弹出 | 多显示器、游戏场景、焦点丢失和拖放体验 |
| 外观与配置 | 皮肤、夜间模式、双语界面、透明/玻璃效果；设置备份和恢复 | 可视化定制深度、迁移配置所需步骤 |

## 主程序功能

### 搜索与启动

- 统一搜索结果列表；上下键选择、回车执行。可设置 `Ctrl/Alt + 数字键` 启动对应结果、单击直接打开，以及列表上下移动快捷键。搜索结果数量上限可调。
- RapidFuzz 模糊匹配可开关，并可设置分数阈值；中文搜索支持全拼、小鹤、国标、紫光、拼音加加、智能 ABC、搜狗、微软、自然码等拼音方案。具体排名质量仍需用样本实测。
- 搜索框可自定义提示词或使用皮肤提示词；可保留、选中上次搜索词；Esc 行为可选关闭、清空、先清空再关闭或无操作；可指定弹出时切换至中文、英文或自定义输入法。
- 主面板唤出/隐藏快捷键可设置为组合键、单击键或双击键；可设置显示设置界面的快捷键。`CLAUDE.md` 记载 Alt+K 为快捷键，但实际默认值以当前用户配置和热键注册结果为准。

### 文件与应用入口

- Folder 插件可按 `config_folder_plugin.json` 索引指定目录和开始菜单；配置包含是否递归、仅索引文件、扩展名、排除词/项目和重命名映射。附带图形化索引管理器，可查看和管理来源。
- 可选索引 UWP 应用、注册表中的应用、`%PATH%` 可执行文件和路径本身；可选择用 Everything SDK 索引/查找文件，也可走本地遍历。另有独立 Windows Search 插件使用系统索引服务。
- 文件结果支持常规启动及管理员权限启动、打开文件或快捷方式目标所在位置、复制文件/目标路径，以及从结果拖出文件；还提供附带剪贴板参数打开、快捷键操作和损坏快捷方式修复工具相关实现。部分功能取决于 Folder 插件配置及辅助程序。
- 常用跳转插件将退出、重启、查看配置、打开索引管理器、帮助及可选的更新/反馈/项目主页放入搜索结果。

### 窗口、外观与日常使用

- 支持开机启动、托盘图标、静默启动、以管理员身份启动主程序、主窗口置顶和鼠标穿透。
- 弹出位置可选择上次位置、光标所在屏幕、前台窗口所在屏幕、前台窗口范围内或固定第 1～3 屏；支持水平/垂直偏移及锁定位置。
- 可在全屏应用、置顶全屏应用或指定游戏进程处于前台时阻止主面板弹出。打开结果后是否关闭、失去焦点如何处理均可配置；失焦策略包含允许拖放文件。
- 有皮肤选择、日/夜主题和跟随系统模式，支持皮肤资源、弹出音效配置、Aero 玻璃/透明及自定义控件。界面语言可跟随系统或切换中文、英文。
- 设置由默认 `settings.json` 与用户配置合并；提供打开配置目录、备份和恢复设置的入口。
- 提供 GitHub Release 更新检查入口和便携包更新相关实现；`settings.json` 仍将“自动检查更新”标注为“未完善”，因此不要把完整自动更新视为已验证能力。

## 插件功能目录

“默认随主程序构建”指当前 `CMakeLists.txt` 的 Ninja/MSVC 路径下列入 `PLUGIN_DEPENDENCIES` 的目标。所有下表插件均有源码并被 `add_subdirectory` 纳入 CMake；“可选”表示当前该构建路径不会因构建主程序而自动构建它，实际发行包也可能有历史 DLL，比较前应检查目标包的 `plugins` 目录及启用状态。

| 插件 | 可对比的功能 | 当前 Ninja 主程序构建 |
| --- | --- | --- |
| Folder | 自定义目录、开始菜单、UWP、注册表应用、`%PATH%` 索引；图形化索引管理及文件操作 | 默认 |
| RunningApp | 搜索当前运行窗口并切换到窗口；提供进程相关操作 | 默认 |
| Bookmark | 索引 Chromium 类浏览器书签；可设触发前缀、URL 匹配、浏览器路径和副浏览器打开 | 默认 |
| CherryTree | 搜索 CherryTree 数据库/多文件笔记目录 | 默认 |
| JetbrainsWorkspaces | 搜索 JetBrains IDE 历史项目 | 默认 |
| FeatureLaunch | 搜索主程序常用操作与配置入口 | 默认 |
| PluginBrowser | 浏览插件清单并用回车切换启用状态 | 默认 |
| WebSearch | 自定义搜索引擎关键字和 URL 模板；搜索管理器、主/副浏览器 | 默认 |
| NodeJsPlugin | 通过独立 Node.js 进程运行 JS 插件，提供 JSON-RPC 桥接；兼容部分 Flow Launcher/Wox 格式 | 默认；运行需 Node.js |
| AirPods | 输入 `airpods` 查看已连接 Apple 耳机电量/充电状态 | 默认；需兼容设备 |
| BrowserHistory | 索引浏览器访问历史 | 可选 |
| VSCodeWorkspaces | 搜索 VS Code 历史项目 | 可选 |
| VisualStudio | 搜索 Visual Studio 最近项目和解决方案 | 可选 |
| EverNote | 索引 Evernote 笔记数据库 | 可选 |
| OneNote | 索引本地 OneNote 笔记 | 可选 |
| TextFile | 索引指定目录中的文本文件 | 可选 |
| Registry | Windows 注册表项目导航 | 可选 |
| Service | 搜索和管理 Windows 服务 | 可选 |
| WindowsSearch | 使用 Windows 系统索引服务搜索文件和文件夹 | 可选 |
| CalcExprtk | 输入表达式进行科学计算 | 可选 |
| UnitConverter | 长度、质量、温度、面积、体积、速度等单位转换 | 可选 |
| ValueGenerator | UUID v1/v3/v4/v5/v7、MD5/SHA 哈希、Base64/URL 编解码、Data/Hex 转义与反转义 | 可选 |
| SmallToolBox | 二维码生成、颜色格式转换 | 可选 |

`Example` 是插件开发示例，`PluginTest` 是测试程序，不作为终端用户功能计入。Visual Studio 生成器分支的插件依赖清单与上述 Ninja 清单不同，应按实际构建产物重新确认。

## 扩展与技术特征

- 原生插件以独立 DLL 提供搜索结果和执行动作；宿主暴露配置、拼音预处理、搜索匹配、图标、回调及插件目录等 API。插件浏览器可切换启用状态。
- Node.js 桥接支持模块式 `init/query/execute` 和部分 Flow Launcher 命令行插件格式，脚本运行于独立进程。兼容性文档仍有待办项，不宜宣称支持全部第三方插件。
- 原生 C++17、Win32/GDI+/Shell 界面，支持 x64/x86 构建。README 将 Windows 7+ 列为目标；新插件、更新器及第三方依赖在旧系统上的表现应实测。
- 项目以 MIT 许可证发布，可免费使用和用于商业用途。
